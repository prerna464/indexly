How the numbers work

Methodology

A plain-language explanation of how benchmark returns, custom date ranges, and the Growth of 100 comparison are calculated.

Data source and update frequency

BenchReturn uses daily closing values for each benchmark index — S&P 500, NASDAQ, STOXX 600, Hang Seng, and Nifty 50 — sourced from publicly available market data. Each index updates once per day, after that market's official close, so figures shown reflect the most recently completed trading session rather than live or intraday prices.

How percentage return is calculated

For any selected time range, BenchReturn takes the closing value on the start date and the closing value on the end date, then calculates the percentage change between the two:

Return % = ((End Close − Start Close) ÷ Start Close) × 100

This is a close-to-close calculation only. BenchReturn does not use intraday highs, lows, or live tick data at any point — every figure shown is based on a confirmed end-of-day closing value.

Handling weekends and market holidays

Stock exchanges are closed on weekends and on public holidays, and holiday calendars differ by country — for example, Nifty 50 follows Indian market holidays, while STOXX 600 follows the pan-European exchange calendar. Because of this, a requested date may not always correspond to an actual trading day.

When this happens, BenchReturn resolves the date by stepping back through the actual sequence of recorded trading days until it finds the most recent session that genuinely occurred — rather than estimating based on a fixed number of calendar days. This means weekends and holidays are skipped automatically and precisely, based on which days each index actually traded, not on an assumption of "five trading days per week." This approach is applied consistently across both preset ranges (1D, 5D, 1M, 3M, 6M, YTD, 1Y) and custom date ranges.

Preset ranges

Each preset button calculates its starting point relative to the most recently available trading day, then applies the trading-day resolution described above. For example, selecting "1M" finds the closing value from one month prior to the latest session and compares it to the latest close.

Custom date range

The Custom option lets you choose any start and end date directly. If either date falls on a weekend or holiday, Indexly uses the closest actual trading day at or before the date selected, using the same resolution logic described above.

Growth of 100 view

This view answers a simple, practical question: how would each index's value have grown or shrunk over the selected period, relative to where it started? BenchReturn rescales every index to a common starting value of 100 on the first day of the selected range, then tracks that value forward based on the index's actual day-by-day percentage movement.

This makes it possible to visually compare indices that trade at very different price levels and in different currencies — such as NASDAQ and Hang Seng — on the same scale, since the comparison is based on relative movement rather than absolute index value or currency.

Short-term comparisons across time zones

Global markets close at different times — for example, Nifty 50 closes hours before European markets, which in turn close hours before US markets finish trading. This means a "1D" or "5D" comparison reflects each market's most recent available close at the time of the daily data update, not a single simultaneous moment in time. For this reason, short-term comparisons across markets in different time zones should be interpreted with this timing difference in mind. Longer ranges (1M and beyond) are far less affected, since a few hours' offset has minimal impact on a multi-week or multi-month return calculation.

What this comparison does not include

Index levels are typically quoted in their local currency and do not account for currency conversion, dividends, dividend reinvestment, or trading costs. BenchReturn's comparisons reflect relative price movement only, not total return on an actual investment.

Informational purposes only
